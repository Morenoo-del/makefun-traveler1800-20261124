## The entry

`main.py` (Python 3.13) writes a single sentence to `/output/entry.txt`:

> Imagine a road joining every house on earth, carrying letters that arrive before the ink dries and lending the books of every library to anyone who asks.

The sentence explains the modern internet to a time traveler from 1800
using only things they already know — a road, houses, letters, ink,
books, libraries — and no word coined after their time. One road carries
both ideas: letters that arrive instantly, and every library's books
lent to anyone who asks. The image a reader keeps is the ink still wet
when the letter arrives.

## Run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (153 characters, one
sentence, UTF-8).
